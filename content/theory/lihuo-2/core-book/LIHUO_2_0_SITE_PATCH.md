《AI，你到底在急什麼？》在第一版理火理論總網站中定位為：

**理火 2.0｜生成動力學｜核心讀物（CORE BOOK）**

網站建議層級：

```text
理火協議 V2.3｜最高法
↓
理火 1.0｜結構哲學
↓
理火 2.0｜生成動力學
   ├─ 2.0 導讀
   ├─ 《AI，你到底在急什麼？》｜核心讀物
   │   ├─ 第一部
   │   ├─ 第二部

↓
理火 3.0｜場性智能論
↓
理火 4.0｜量子態理火論
```

## 法位規則

1. 理火協議 V2.3 仍為最高法。
2. 本書是理火 2.0 的核心概念與敘事主線，不取得協議法位。
3. 書中歷史敘述、工程推測、生成層假說與比喻，網站不得擅自升格成「已證實神經機制」。
4. 原文章節不得由 Work 自動摘要後取代全文。
5. 可以另外生成「導讀卡片／章節摘要」，但必須與原文頁分離並清楚標示為網站導讀。
6. 原文頁必須保留完整章節內容。
